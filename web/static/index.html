      KNOW THE SCOPE

      Integrity, with clear limits.

      The receipt commits to the task specification and response bytes. Model and usage fields inside those bytes are indirectly bound when the supplied content matches.

      Transformed API responses may differ from the upstream bytes the TEE signed. Historical evidence with expired certificates is refused. Request-ID lookup uses the public buyer evidence API; only your own requests are accessible.
